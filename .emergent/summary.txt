<original_problem_statement>
The user wants to build a comprehensive HOA (Home-Owners Association) management system. Initially, an MVP was created. The user then provided a large set of new requirements for bug fixes, feature enhancements, and new modules.

**PRODUCT REQUIREMENTS (from initial PRD and subsequent user requests):**

**Core Functionality:**
-   Unit & Owner Management.
-   Billing & Payments (Annual formula-based and manual).
-   Reporting.
-   JWT Authentication.

**Phase 1 - Fixes & Enhancements (Mostly Complete):**
1.  **Bug Fix - Login Flow:** Fix the screen getting stuck after logging out as an owner and logging back in as an admin.
2.  **Owner Read-Only Access:** Owners must have read-only access to all modules (Dashboard, Units, Billing, Activities, Reports, Documents), seeing the same data as an Admin but without edit/delete capabilities.
3.  **Owner Editing Rights:** Owners must be able to edit their own profile information (Name, Phone, Email, etc.) and save the changes.
4.  **UI Fix - Login Screen:** Remove hardcoded demo credentials from the login page.
5.  **Dashboard Financial Metrics:** Add four key financial metrics to the dashboard, visible to all roles: Reserve Balance, Total Collected, Payments Received (This Year), and Total Expenses (This Year).
6.  **Profile Data Bug:** Fix the issue where the profile page sometimes appears with blank user data.

**Phase 2 - Critical Accounting & Security Fixes (Partially Complete):**
8.  **Full Audit Log:** Enhance the Activity Log to be a full audit trail for all financial and data changes, including old/new values, the user who made the change, a timestamp, and a reason for the change. Add filters for date range and user role.
9.  **Ledger Integrity:** When an admin edits a posted financial record (payment, expense, etc.), they must be required to provide a Reason for change. This action must be logged in the audit trail.
10. **Backend RBAC Enforcement:** Ensure all API endpoints are protected, blocking unauthorized actions (e.g., an owner trying to edit a financial record) at the backend, not just by hiding UI elements.

**Phase 3 - New Modules (In Progress):**
11. **Document Management Module:**
    -   A new Documents tab for storing and organizing HOA files.
    -   Default folder structure (Legal, Financials, etc.).
    -   Admin/Treasurer can create/rename/delete folders and upload files (PDF, DOC, JPG, etc.).
    -   Owners have read-only access to browse, view, and download documents.
    -   Features to include: file search, metadata tracking, and in-app preview.
